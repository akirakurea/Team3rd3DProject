## 어느 문서를 고치면 되나요?

현재 기능 규칙이 바뀌면 해당 기능 문서를 수정하고, 왜 바꿨는지는 기존 [작업 로그](../PLAYER_WORK_LOG.md)에 추가합니다. 빠른 사용 설명은 기존 [구현 설명서](../PLAYER_IMPLEMENTATION_GUIDE.md)에 유지합니다. 과거 기록을 현재 설명으로 덮어쓰지 않습니다.

이 문서의 HTML은 Markdown을 읽기 쉽게 모아 둔 출력물입니다. 원본 Markdown을 고친 뒤 HTML도 다시 생성해야 두 형식이 일치합니다. 작성 도구와 외부 초안은 이번 게임 구현 파일에 포함하지 않았습니다.

## 문서 기준과 확인 범위

- 현재 코드와 저장된 씬 설정을 확인했습니다. 에디터에만 남은 미저장 상태를 자동 저장하지 않았습니다.
- 실제 코드 발췌, 한 줄씩 풀이, 설정 위치, 수정 방법, 확인 사례를 각 기능에 함께 넣었습니다.
- 과거 플레이 시험과 이번 문서의 정적 검토를 구분했습니다. 3치즈 미지급은 기존 재현 검사에서 재현되지 않아 원인 미확정으로 남겼습니다.
- 현재 Player는 여러 SkinnedMeshRenderer를 사용합니다. 과거의 단일 메시·쿼드·900폴리곤 요청이 현재 Unity 에셋에서 전부 충족된다고 단정하지 않습니다.
- 게임 코드·씬·에셋·메타를 변경하지 않고 문서와 문서 안내·작업 기록만 추가했습니다. 이번 문서의 커밋·푸시는 하지 않았습니다.
